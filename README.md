# Airline Booking Analysis

## Project Overview

This project analyzes airline booking data covering flights, bookings, passengers, and payments.

Python and Pandas were used in Google Colab to clean and prepare the data. The cleaned data was then used in Power BI to create an interactive dashboard.

## Data Processing

The data was processed using Python and Pandas in Google Colab.

- Loaded flights, bookings, passengers, and payments data.
- Checked and handled missing values.
- Removed duplicate records.
- Corrected date, time, and payment data types.
- Processed flight duration into minutes.
- Merged the four datasets.
- Removed sensitive passenger information for privacy.
- Created fields such as route, booking month, and flight date.
- Exported the final cleaned dataset.

## Dashboard

The Power BI dashboard provides an overview of airline bookings, routes, airlines, payments, flight duration, and booking status.

## Conclusion

The project converts raw airline booking data into a clean dataset and an interactive Power BI dashboard. It helps understand booking patterns and other important airline-related information.
